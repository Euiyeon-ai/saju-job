## 2. 배포가 확정한 제약

GitHub Pages = 정적. 아래는 **못 한다**(기획에서 제외):

| 못 하는 것 | 왜 |
|---|---|
| 결과 서버 저장 · 사용자 계정 | DB 없음 |
| LLM API 호출 | 키를 숨길 서버가 없음. 프론트에 박으면 유출 |
| 친구와 결과 비교 (서버 대조) | 백엔드 없음 |

→ 가능한 대체: URL 쿼리스트링으로 결과 공유, localStorage 저장, 계산 전부 브라우저에서.
